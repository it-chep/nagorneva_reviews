# План JS-вставки для Tilda

1. Сначала определить публичный домен API, включить HTTPS и ограничить CORS не `*`, а доменом сайта Tilda. Публичными остаются только `POST /api/v1/doctors_on_map` и `POST /api/v1/reviews/filter`; админские JWT-endpoints в Tilda не используются.
2. Подготовить отдельный минифицированный файл, например `reviews-widget.js`, и разместить его на CDN/S3. В Tilda подключить его в «Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD», а на нужной странице добавить контейнер `<div id="doctor-reviews-widget"></div>` через блок T123.
3. В скрипте хранить только публичный `API_URL`, селекторы и настройки карты; никаких ключей S3, JWT или admin-паролей. Инициализацию обернуть в `DOMContentLoaded` и проверку наличия контейнера, чтобы скрипт был безопасен на всех страницах сайта.
4. Сделать UI виджета изолированным: CSS префикс `nrw-` или Shadow DOM, чтобы стили Tilda не ломали форму и карточки. Добавить фильтр «Курс», поле радиуса и кнопку «Найти».
5. При первом рендере запросить `POST /api/v1/doctors_on_map` с центром карты/геолокацией пользователя и `radius_km`. Построить маркеры по `lat/lon`; в popup показывать `name`, `city`, фото только если его вернул сервер, и список отзывов с названием курса.
6. При изменении курса или области карты вызвать `POST /api/v1/reviews/filter` с `course_id`, координатами и радиусом. Отобразить список и счетчик результатов. Добавить `AbortController`, чтобы отменять устаревший запрос при быстрых изменениях фильтра.
7. Обработать состояния: skeleton во время загрузки, нейтральный пустой результат, понятная ошибка сети с кнопкой повтора. Не использовать бесконечную загрузку: добавить лимит/пагинацию в API перед ожидаемым ростом базы.
8. До публикации проверить на опубликованной тестовой Tilda-странице: desktop/mobile, CORS preflight, отсутствие смешанного контента, корректность скрытия ПД, медленная сеть и отказ API. Подключить Sentry/метрику только с публичным DSN, если потребуется наблюдаемость.

Рекомендуемый следующий backend-шаг до production: добавить `limit`/`offset` в публичные запросы, server-side rate limit и разрешённый список доменов CORS в конфигурации.
